LESSON 02 // CANVAS GEOMETRY INTERACTION

피타고라스 정리와 두 점 사이의 거리

좌표평면 위 직각삼각형 빗변 피타고라스 정리로부터 유도되는 거리 공식의 직관적 증명

PYTHAGOREAN FORMULA: a² + b² = c²

📍 직교좌표평면 탐구 캔버스

점 A(파란색)와 점 B(주황색)를 마우스나 손가락으로 드래그하여 좌표를 이동하세요.

DRAG POINTS A AND B TO SEE LIVE CALCULATIONS

POINT A (x₁, y₁)

( -3 , -2 )

POINT B (x₂, y₂)

( 3 , 4 )

실시간 피타고라스 계산판 a² + b² = c²

[STEP 1] 가로 및 세로 변의 길이

가로 (밑변 a): |x₂ - x₁| |3 - (-3)| = 6
세로 (높이 b): |y₂ - y₁| |4 - (-2)| = 6

[STEP 2] 피타고라스 정리 수식 대입 (a² + b²)

6² + 6² = 36 + 36 = 72

빗변의 제곱 c² = 72

[STEP 3] 두 점 A, B 사이의 거리 (d = √c²)

d = √[(x₂-x₁)² + (y₂-y₁)²]

√72

≈ 8.485

EDITORIAL DISCUSSION Q&A

좌표평면 위에서 점을 조작해 본 후 아래 질문에 대해 깊이 생각해 보세요.

Q1

"두 점 사이의 거리를 구할 때 왜 직각삼각형을 이용할까요?"

[수학적 기하 연결성]

좌표평면 위 선분의 길이를 직접 재기 어렵지만, x축과 y축에 평행한 보조선을 그으면 항상 직각삼각형이 만들어지기 때문입니다.

가로와 세로의 길이는 좌표의 차이로 손쉽게 얻을 수 있으므로 피타고라스 정리를 적용해 빗변(거리)을 구합니다.

Q2

"피타고라스 정리(a² + b² = c²)와 '두 점 사이의 거리 공식'은 어떤 관계가 있나요?"

[공식 유도 관계]

거리 공식 d = √[(x₂ - x₁)² + (y₂ - y₁)²]은 피타고라스 정리 c = √(a² + b²)의 변 $a, b$ 위치에 가로 $|x₂ - x₁|$과 세로 $|y₂ - y₁|$을 그대로 대입한 동일한 식입니다.

즉, 공식 암기 없이 피타고라스 원리 하나로 거리 공식을 항상 유도할 수 있습니다.
